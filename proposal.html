1) 서비스 기획배경 및 필요성

※ 서비스를 기획·구상하고 제안한 배경과 필요성 작성

1. 서비스 기획 배경
  • 방한 관광객 동선 편중 문제 인식: 해외(일본) 현지 투어 가이드 실무 경험 분석을 통해, 방한 외국인 관광객의 여행 동선이 서울·부산 등 대도시 권역에 집중되는 경향을 확인하였음. 경주·전주·안동 등 풍부한 역사문화 자원을 보유한 지방 중소 거점 도시가 개별자유여행객(FIT)의 자율적 동선 내에서 충분히 체험되지 못하는 구조적 한계를 문제로 인식함.
  • 단체 관광(GIT) → 개별자유여행(FIT) 패러다임 전환: 최근 방한 관광 시장은 단체 관광(GIT) 중심에서 개별자유여행(FIT) 중심으로 수요 패러다임이 급속 전환되고 있음. 특히 체류 시간이 제한적인 지방 중소도시에서 반나절 이상의 일정을 요하는 기존 가이드 투어 방식은 FIT 여행객의 유연한 일정 운용과 상충하는 구조적 한계가 있음.
  • 기존 오디오 가이드의 사용자 경험(UX) 한계: 현행 오디오 가이드 서비스는 사용자가 각 명소에서 해당 해설을 직접 검색·선택·재생하여야 하는 조작 부담이 존재함. 이로 인해 이동 중 몰입감이 저해되며, 디지털 취약 계층을 포함한 다양한 연령층의 실질적 활용에 제약이 따름.
2. 서비스 필요성
  • 단체 투어와 기존 오디오 가이드의 중간 지점(Middle-ground) 수요 충족: 일정의 자유도가 제한되는 단체 가이드 투어와, 사용자가 능동적으로 해설을 탐색해야 하는 기존 오디오 가이드 사이의 공백 수요를 타겟팅함. GPS 기반 자동 재생을 통해 여행객이 이동만 하면 현장 맞춤형 해설이 자동 제공되는 '지능형 자율 여행 보조 서비스'를 구현함.
  • 스토리텔링 기반 정서적 현장 몰입 경험 창출: 단순 건축물 관람 수준을 넘어, 역사적 맥락(예: 불국사 다보탑의 단일 사자상 존재 이유, 무영탑 전설 등)을 현장에서 제공하는 맞춤형 오디오 콘텐츠를 통해 사전 영상 시청(유튜브 등)과 차별화된 현장 몰입감을 부여함. 단순 시각적 관람 체험을 감정적·역사적 경험으로 승화시켜 체류 만족도 및 재방문 의향을 제고함.
  • 공공데이터 연동을 통한 서비스 지속성 및 확장성 확보: 한국관광공사 OpenAPI 연동을 통해 관광 정보의 실시간 갱신 기반을 마련하고, 지속적인 명소 콘텐츠 확장이 가능한 구조로 설계함. 경주를 MVP 실증 거점으로 설정하여 서비스 모델을 검증한 후, 목포·전주·안동 등 타 지방 중소 거점 관광 도시로의 수평적 확산을 도모함.

3. 서비스 차별성
  • GPS 위치 기반 자동 전환 재생: 기존 오디오 가이드는 사용자가 명소마다 해설을 직접 재생하여야 하나, 본 서비스는 GPS 반경 진입만으로 현장 맞춤형 해설이 자동 재생됨. 현재 재생 중인 가이드의 순서와 무관하게, 반경 진입 즉시 해당 스팟에 적합한 해설로 자동 전환되어 이동 중 지속적인 몰입 경험을 제공함.
  • 포토스팟 현장 안내: 검색만으로는 발견하기 어려운 현지 인기 포토스팟을 지도 상에 별도 표시하여, 사진 촬영 명소를 놓치지 않도록 안내함.
  • 위치 기반 자동 지도 포커싱: 투어 코스 내 명소 선택 시, 해당 명소의 지도 위치로 자동 이동 및 포커싱 처리. 지리에 익숙하지 않은 방한 외래 관광객이 각 명소의 상대적 위치를 직관적으로 파악하고 효율적인 이동 동선을 계획할 수 있도록 지원함.
  • 데이터 기반 서비스 고도화: 사용자 행동 데이터(가이드 시작·완주율·핀 탭 빈도 등)를 수집·분석하여 콘텐츠 품질 및 동선 최적화에 지속 반영함.
  • 비설치형(No-Install) 즉시 이용: 앱스토어 설치 과정 없이 QR코드 접속만으로 iOS·Android 공통 즉시 이용 가능. PWA(Progressive Web App) 방식으로 홈 화면 추가 시 앱에 준하는 사용 환경 제공.

2. 데이터 활용 방식
  • 명소 운영 정보 실시간 연동: detailIntro API를 통해 각 명소의 운영시간·입장요금 정보를 자동 반영함으로써 정보 오류로 인한 여행객 불편을 방지하고 서비스 신뢰도를 제고함.
  • 신규 명소 콘텐츠 확장 기반 마련: areaBasedList API를 통해 경주 및 타 지역 관광지 데이터를 조회하고, 현장 답사 후 오디오 콘텐츠를 순차 탑재하는 구조적 확장 프로세스를 구축함.
  • 오디오 스크립트 품질 제고: detailCommon의 관광지 개요(overview) 데이터를 오디오 해설 스크립트 초안 작성의 기초 자료로 활용하여 정보 정확성을 담보함.
  • 위치 기반 주변 명소 추천: locationBasedList API와 사용자 GPS 좌표를 연동하여, 현재 위치 반경 내 미방문 관광지를 추천하는 기능을 구현할 예정임.

  • 한국관광공사 OpenAPI와의 지속적 연동으로 공공 관광 데이터의 실질적 활용도를 제고하고, 데이터 품질 기반 서비스 신뢰도 확보
  • 장기적으로 관광 안내와 교통 편의를 통합한 방한 여행 동반 플랫폼으로 성장하여, 한국 지방 관광의 접근성 및 국제 경쟁력 제고에 이바지함
